# 无额外写后探测的混合轨迹验收

本轮目标是把原有带逐写 Get 的 mixed 轨迹与无额外写后 Get 的轨迹分开，并形成
同输入、完整结果校验、真实落盘、各自新进程重开的验收闭环。工程入口见
[工程验收说明](../../../docs/acceptance.md)。

## 实现

`ltm_bench --workload=mixed` 新增 `--trajectory=checked|measure`。默认 checked
保留 schema 1 和原有作用范围；measure 使用 schema 2 与
`api_calls_without_write_probes`，在执行路径中省去额外 Get，而非只从时间中扣掉。
两个入口都逐次核对读返回，末尾核对全部键、MBR、载荷和双树一致性，再检查点、
关闭、用新进程重开验证。

两种轨迹仍有内联独立参考计算和逐 API 统计快照，均在结构化输出声明；API 延迟
不含这些耗时，墙钟吞吐包含。未把本轮结果描述为完全无观测性能或设备物理 I/O。

额外输出 `write_probe_calls`、原 Hybrid 查询计数增量 `measured_query_calls`、
`uncounted_not_found_gets` 和完整 `measured_read_requests`。原查询统计不计未命中
Get，不能直接要求它等于请求次数；未命中数由成功验证的操作状态记录，并由
Python 从独立键历史复算。每 300 次操作，checked 请求数 300、其中写后探测 90；
measure 请求数 210、探测次数和耗时及全部探测计数均为零。

mixed 的独立 KNN 参考由边界距离检查补为完整 `(距离, 键)` 排名与载荷检查，新增
回归拒绝同距错键、颠倒顺序和错误载荷；旧暴力查询与核心树实现未修改。

## 验收与证据设计

```powershell
python -B scripts/accept_mixed_measure.py --phase all
python -B report/acceptance/mixed_measure_20261016/verify_evidence.py
```

三种配置顺序执行，避免普通基准与本轮其他配置的压力同时运行，但未隔离系统
后台活动。每种配置：两类轨迹 × 12/128 帧 × 三次重复，共 12 次运行和 12 次
独立进程重开。固定 512 条初始记录、300 次操作、30 次预热、种子 42，输入
由独立模型先生成；其中 Put 新增/更新/重插及 Erase 存在/缺失的数量固定且可复算。

普通与 ASAN 完整 ctest、TSAN 相关三项、每配置两个结构守门、18 项协议检查和
跨进程主链路分别记账。协议拒绝 schema 混用、伪造零探测、调用数偏移、坏时间、
缺字段、已有库覆盖、未知轨迹和真实超时。旧 v1 原始结果另做兼容解析，历史
记录保持原版本。

独立核对脚本重新解析原始输出，与存储 JSON 逐项比较；由样本复算类型数量、
分位数、计时与 I/O 总和、CSV 和重复摘要；核对各库文件、执行程序、源码快照和
历史证据哈希。不同轨迹及配置的四个指纹与最终记录清单必须一致。

初次 ordinary 完整测试及结构守门通过后，协议校验拒绝了把原查询统计当成全部
读请求的假设。该轮保留为失败，增加未命中 Get 的独立记账后先通过协议检查，
再运行最终三配置；未改动核心查询统计语义，也未把失败结果混作最终通过。

第一版三配置验收还发现主链路 Python 包装器只支持 Windows：Linux 即使指定
`--skip-build` 仍查找 Visual Studio，并固定 `.exe` 文件名。已补齐按平台选择工具链、
构建方法及程序后缀；Linux 的跳过构建和全新目录配置/编译两种路径均另行实跑，
各自完成写入和新进程重开。修复后统一版本重新执行三配置，旧结果保持原记录。

每轮验收使用 `build-accept-mixed-配置-时间` 的新目录，并在清单记录实际位置，
后续重跑不会覆盖先前通过或失败轮次的二进制。

## 临时文件清理

清理仅涉及可生成的构建对象、编译器中间符号、链接缓存与 Python 字节码。实际
删除与路径检查记录见 `report/maintenance/cleanup_*/manifest.json`；源码、库、程序、
根调试符号、数据库和原始验收证据保留。dry-run 只是计划，不能计入实际清理大小。

## 边界与后续

本轮是单线程、有界 mixed 的验收扩展；尚未据此给出无观测吞吐、策略优劣、系统
内存超限、冷启动或设备断电结论。下一步可在同一版本测 KNN 单/多读者及不同 k，
再扩大工作集并做冷热策略消融。原纯内存基线仍按用户要求取消。
